## 🌟 What is this?

**Mental Health Support** is an AI-powered chatbot web app designed to provide empathetic, judgment-free support to people dealing with **anxiety, stress, depression, loneliness**, and more.

Built with Python & Flask, it uses a trained machine learning model to understand what you're going through and respond with care — right from your browser, no sign-up needed.

🔗 **Try it live:** [mental-health-support-egri.onrender.com](https://mental-health-support-egri.onrender.com/)

---

## ✨ Features

| Feature | Description |
|---|---|
| 💬 **Empathetic AI Chat** | Responds to your feelings with understanding and care |
| 🎤 **Voice Input** | Speak your thoughts — no typing needed |
| ⚡ **Quick Prompts** | One-tap starters like *"I feel anxious"* or *"I can't sleep"* |
| 📞 **Crisis Helplines** | Displays verified Indian mental health helplines |
| 🌐 **Zero Setup** | Fully web-based — open and talk instantly |

## 🛠️ Tech Stack

```
🐍 Backend     →  Python + Flask
🤖 ML Model    →  Scikit-learn (pre-trained .pkl)
🎨 Frontend    →  HTML + CSS + JavaScript
🎤 Speech      →  Web Speech API + SpeechRecognition
☁️ Hosting     →  Render (Free Tier)
```

## 🚀 Run Locally

### 1. Clone the repo
```bash
git clone https://github.com/Ayesha037/MENTAL_HEALTH_SUPPORT.git
cd MENTAL_HEALTH_SUPPORT
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Start the server
```bash
python app.py
```

### 4. Open in browser
```
http://localhost:5000
```

## ☁️ Deploy Your Own

> This app is deployed on **Render** (free tier). You can fork and deploy your own in minutes.

```
1. Fork this repo
2. Go to render.com → New Web Service
3. Connect your GitHub repo
4. Start command: python app.py
5. Hit Deploy 🚀
```

> ⚠️ **Cold Start Notice:** Render's free tier sleeps after 15 min of inactivity.
> First load may take ~30–50 seconds — totally normal!
